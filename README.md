# Panel de inventario · demo

Vista previa **estática** de un panel de inventario con alertas, previsión de demanda y asistente de IA, preparada para revisar funciones y diseño.

- Todos los datos son **ficticios** (productos, cantidades, costes, proveedores y pedidos inventados).
- El asistente de IA muestra **respuestas de ejemplo**; en la versión real consulta los datos en el momento.
- Lo que se guarda en la demo (alertas personalizadas, alertas vistas) solo queda en el navegador de quien la usa.
